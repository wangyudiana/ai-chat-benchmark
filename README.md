# 竞品采集台 · AI Chat Benchmark

在自己电脑上运行的 **AI 对话产品竞品评测工作台**：把一批问题同时发给 ChatGPT、豆包、DeepSeek、Kimi 等产品，自动等回答结束、截长图、提取回答文本、记录耗时，再用 AI 按你定的评测目的逐条打分、写竞品结论，导出 Excel 和调研报告。

- 全部在本机运行，账号登录状态、采集结果都只存在你自己的电脑上
- 用浏览器操作，不需要写代码；也不需要各家的 API，测的是用户在网页上真实看到的回答
- 详细操作见 **[使用说明.md](使用说明.md)**

---

## 能做什么

| | |
|---|---|
| **批量采集** | 每行一个问题，支持分类、多轮追问、Excel/CSV 导入、题库；多个产品同时跑，每题可跑多次看稳定性 |
| **按产品选模型和模式** | 例如 ChatGPT「工作 · GPT-6.1 Terra · 高」、Kimi「K3.1 Pro · 极致」、千问「思考研究」、DeepSeek「深度思考」。产品改版后可一键从页面更新选项，或录制一组点选 |
| **截图** | 整段对话自动滚动拼成长图；采集时自动收起侧边栏，历史对话不会进截图 |
| **回答文本** | 按网页排版转成 Markdown（标题、列表、表格、代码块、公式），自动去掉思考过程、引用卡片、按钮文字 |
| **计时** | 首次输出、正文开始、回答完成时间 |
| **防出错** | 遇到验证码、登录框、额度提示时只暂停该产品并提醒你接管，处理完自动继续；失败自动重试；页面改版时自动退回通用识别 |
| **AI 分析** | 每个任务写自己的评测目的和评分维度（可让 AI 推荐）；AI 隐去产品名、打乱顺序后逐条打分；按内置分析框架写结论；人工打分优先 |
| **导出** | 调研报告（HTML / Markdown）、截图对照 Excel（格子里就是截图）、评分明细 Excel、全部打包 |
| **其他** | 电脑网页 / 手机网页（H5）两种设备；无痕对话；手机上看进度和结果 |

## 快速开始

### 1. 准备

- **电脑**：macOS 或 Windows
- **Python 3.9 或更高版本**：Mac 打开「终端」输入 `python3 --version` 能看到版本号就行；没有的话到 [python.org](https://www.python.org/downloads/) 下载安装（Windows 安装时勾选 **Add Python to PATH**）
- **Google Chrome**（推荐）：平台默认用本机的 Chrome 打开各产品，没有的话会自动改用内置浏览器
- 第一次启动需要联网下载依赖，大约 300 MB

### 2. 下载

在 GitHub 仓库页面点绿色的 **Code → Download ZIP**，解压到一个固定的位置（比如「文稿」）。会用 git 的话：

```bash
git clone https://github.com/<你的用户名>/ai-chat-benchmark.git
```

### 3. 启动

- **Mac**：双击 `启动.command`
  - 提示「无法打开，因为来自身份不明的开发者」：右键点它 → 打开 → 再点「打开」，只需一次
  - 提示「没有执行权限」：打开终端，输入 `chmod +x ` （末尾有空格），把 `启动.command` 拖进终端窗口，回车，然后再双击
- **Windows**：双击 `启动.bat`

第一次启动会自动安装依赖，大约 2–5 分钟，之后几秒就能打开。浏览器会自动打开 **http://127.0.0.1:8848**，这就是平台界面。

用的时候**不要关掉那个黑色的终端窗口**，关掉平台就退出了。启动脚本会阻止电脑自动休眠，但合上笔记本盖子仍会中断采集。

### 4. 第一次使用

1. **产品** 页：给要测的产品逐个点「登录」，在弹出的浏览器窗口里登录（建议用测试账号），回来点「登录完成」
2. 同一页点「**试跑**」：真的问一个问题，逐项检查输入框、回答、截图、侧边栏、模型选择能否识别，有问题一眼就能看出来
3. **设置** 页（可选，推荐）：配置分析模型，用于 AI 打分和写结论。支持 OpenAI 兼容接口（DeepSeek、千问、豆包、Kimi 等）和 Claude，点服务商按钮自动填地址，再填 API Key 和模型名
4. **新建采集**：写问题 → 选产品 → 按需选每个产品的模型/模式 → 写评测目的 → 开始采集（`⌘/Ctrl + 回车`）
5. **任务** 页：看实时进度；完成后看结果、对比打分、AI 分析、导出

## 常见问题

**双击启动后一闪就没了 / 提示没有 Python**
先装 Python 3.9+（见上文），装完重新双击。

**提示端口 8848 被占用**
平台可能已经在运行了，直接打开 http://127.0.0.1:8848 。确实要换端口：在终端里进入这个文件夹，运行 `./启动.command --port 8850`。

**采集时提示「需要你接管」**
遇到验证码、登录框或额度提示了。对应产品的浏览器窗口会切到前台，在里面完成验证或登录，页面恢复正常后会自动继续；其他产品不受影响。

**某个产品的回答取得不对 / 截图里有多余的东西**
各家网页经常改版。先在「产品」页对它点「试跑」，看哪一项失效；再到它的「设置 → 高级」里调整。详见使用说明第八节。

**产品出了新模型，下拉里没有**
「产品」页点它的「模型/模式 · 录制」→「从页面更新」，或直接手填名字，或「录制一组选择」。

**想在手机上看结果**
改用 `启动-手机可看.command` 启动，平台左下角会显示一个地址，手机连同一个 Wi-Fi 打开即可。

**怎么升级到新版本**
下载新版本后，把旧文件夹里的 `data` 和 `profiles` 两个文件夹拷到新文件夹里（这样任务、设置和登录状态都保留），再启动新文件夹里的 `启动.command`。

## 数据与隐私

所有数据都在这个文件夹里，不会上传到任何地方（AI 分析时，回答内容会发给你在「设置」里配置的分析模型）：

| 位置 | 内容 |
|---|---|
| `data/jobs/` | 每个任务一个文件夹：截图、回答、评分、报告 |
| `data/settings.json` | 设置，**含分析模型的 API Key，不要发给别人** |
| `data/sites.json`、`data/site_options.json` | 产品配置、更新过的模型/模式选项、录制的方案 |
| `profiles/` | 各产品的**登录状态，相当于你的账号，不要发给别人** |

分享这个工具给别人时，只发代码（从 GitHub 下载的版本不含以上内容），不要连 `data`、`profiles` 一起发。想恢复成刚下载的状态，删掉 `data` 和 `profiles` 两个文件夹即可。

## 注意

- 自动化访问请遵守各产品的使用条款，采集内容仅用于内部调研。量大时用测试账号、调大采集间隔、分批跑，降低风控风险。
- 时间指标在浏览器里测得，受网络和渲染影响，适合横向比较快慢，不等于接口延迟。
- 采集过程中不要点击、最小化自动打开的浏览器窗口（需要你接管时除外）。

## 给维护者

```
app/
  server.py     本地 Web 服务（标准库），所有接口
  engine.py     采集引擎（Playwright）：发送、等回答、提取、长截图、模型/模式选择、试跑、录制
  adapters.py   各产品的内置适配：页面元素选择器、模型/模式选项（产品改版主要改这里）
  store.py      数据存取，全部是 data/ 下的 JSON
  analyzer.py   AI 打分、按评测目的推荐维度、按分析框架写结论
  report.py     HTML 报告、截图对照 Excel
  exporter.py   评分明细 Excel、Markdown 报告、打包
  compose.py    多产品横向对比拼图
  static/index.html  前端（单文件，无构建）
```

依赖只有 `playwright`、`pillow`、`openpyxl`（见 `requirements.txt`）。手动运行：

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && python -m playwright install chromium
python -m app.server            # 加 --lan 允许同一局域网的手机访问，--port 换端口，--no-browser 不自动打开浏览器
```

产品改版后更新适配：先用「试跑」看哪项失效，到 `app/adapters.py` 改对应产品的选择器或选项；模型名之类的变化，用户在界面上「从页面更新」即可，不用改代码。
